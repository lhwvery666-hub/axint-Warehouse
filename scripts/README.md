# Excel 批量导入脚本使用说明

## 功能概述

`import-excel.ts` 脚本用于将 Excel 文件中的设备数据批量导入到 SQL Server 数据库中。

## 功能特性

1. **自动读取 Excel 文件**：从项目根目录读取 `import_data.xlsx` 文件
2. **数据验证**：自动跳过缺少序列号的行，并打印警告信息
3. **自动维护产品目录**：提取不重复的规格型号，自动插入到 `Product_Catalog` 表
4. **批量导入设备库存**：使用事务批量处理，每 500 条记录为一批，确保数据一致性
5. **进度日志**：实时显示处理进度和统计信息

## Excel 文件格式要求

### 文件位置
将 Excel 文件放在项目根目录下，命名为 `import_data.xlsx`

### 列名要求（第一行必须是标题行）

| Excel 列名 | 数据库字段 | 说明 |
|-----------|-----------|------|
| 序列号 | SerialNumber | **必填**，如果为空则跳过该行 |
| 规格型号 | ModelName | 对应 Product_Catalog 和 Device_Inventory |
| 物料名称 | DeviceName | 当前脚本暂未使用（Device_Inventory 表可能无此字段） |
| 仓库名称 | ProjectLocation | 设备所在的项目地点/仓库 |

### 示例 Excel 格式

```
| 序列号      | 规格型号    | 物料名称      | 仓库名称    |
|------------|------------|--------------|------------|
| SN001      | Model-A    | 设备A        | 北京仓库    |
| SN002      | Model-B    | 设备B        | 上海仓库    |
```

## 使用方法

### 1. 准备 Excel 文件

确保 `import_data.xlsx` 文件已放在项目根目录下。

### 2. 运行导入脚本

```bash
npm run import-excel
```

或者直接使用 tsx：

```bash
npx tsx scripts/import-excel.ts
```

### 3. 查看导入结果

脚本会输出详细的处理日志，包括：
- 读取的行数
- 跳过的无效行数
- 产品目录维护情况
- 设备库存导入进度
- 最终统计信息

## 导入逻辑说明

### 步骤 A：读取并解析 Excel
- 使用 `xlsx` 库的 `readFile` 方法读取文件
- 将第一个工作表转换为 JSON 数组
- 验证数据完整性（检查序列号是否为空）

### 步骤 B：批量写入 SQL Server

#### B1: 自动维护产品目录
- 提取所有不重复的规格型号
- 查询现有产品目录，找出需要新增的型号
- 批量插入新规格型号到 `Product_Catalog` 表（每 100 条一批）
- 自动设置 `DisplayOrder`（基于当前最大值递增）

#### B2: 批量处理设备库存
- 使用 SQL `MERGE` 语句实现 UPSERT（存在则更新，不存在则插入）
- 每 500 条记录为一批，使用事务确保原子性
- 更新字段：`ModelName`、`ProjectLocation`
- 如果某批处理失败，会自动回滚该批次的所有操作

## 注意事项

1. **数据库连接**：确保 SQL Server 数据库已启动，且连接配置正确（`lib/db-config.ts`）
2. **表结构**：确保 `Product_Catalog` 和 `Device_Inventory` 表已创建
3. **字段映射**：如果 `Device_Inventory` 表没有 `DeviceName` 字段，脚本会自动忽略该字段
4. **性能优化**：大批量数据（几千条）会自动分批处理，避免内存溢出
5. **错误处理**：如果某行数据有问题，会跳过并继续处理其他行

## 常见问题

### Q: 提示"文件不存在"
A: 确保 `import_data.xlsx` 文件在项目根目录下，文件名大小写敏感。

### Q: 提示"数据库连接失败"
A: 检查 `lib/db-config.ts` 中的数据库连接配置，确保 SQL Server 服务已启动。

### Q: 部分数据导入失败
A: 查看控制台输出的错误信息，通常是数据格式问题或数据库约束冲突。

### Q: 如何修改批量大小？
A: 编辑 `scripts/import-excel.ts`，修改 `batchSize` 变量（设备库存默认为 500，产品目录默认为 100）。
