# 批次设备选择页面 - 聊天和签字凭证功能

## 📋 概述

在批次设备选择页面（"选择要处理的设备"页面）添加了**工单沟通记录**和**签字凭证**两个功能模块，方便用户在选择设备之前就能查看工单级别的沟通记录和签字照片。

## 🎯 功能说明

### 页面位置
- **文件**: `components/repair-page.tsx`
- **视图**: `batchSelect` 视图
- **触发**: 点击批次工单卡片后进入此页面

### 新增功能

#### 1️⃣ 工单沟通记录
- 使用 `TicketChat` 组件
- 绑定到批次工单的 `batchId`
- 支持实时查看历史消息
- 支持发送新消息
- 显示消息数量

#### 2️⃣ 签字凭证
- 自动从后端获取签字照片（`SignedReportPhoto`）
- 显示"已上传"或"暂无签字凭证"状态
- 提供以下操作：
  - 📸 **查看大图**：在新窗口中查看高清图片
  - 💾 **下载照片**：下载到本地
  - 🔗 **复制链接**：复制图片链接到剪贴板

## 🛠️ 技术实现

### 状态管理
```typescript
const [batchSignedPhoto, setBatchSignedPhoto] = useState<string | null>(null)
```

### 数据获取
在批次任务改变时，通过 API 获取签字照片：
```typescript
useEffect(() => {
  const fetchBatchSignedPhoto = async () => {
    const batchId = currentBatchTask?.batchId || batchContext?.batchId
    if (!batchId) return

    const response = await fetch(`/api/tickets/batch-devices/${batchId}`)
    const result = await response.json()
    if (result.success && result.data.batchInfo) {
      setBatchSignedPhoto(result.data.batchInfo.signedReportPhoto || null)
    }
  }

  fetchBatchSignedPhoto()
}, [currentBatchTask, batchContext])
```

### UI 组件
- **工单沟通记录**: 完整的聊天界面，支持实时交流
- **签字凭证**: 显示照片预览和操作按钮

## 🎨 视觉效果

### 已上传签字凭证
- 绿色状态提示："现场人员已上传签字凭证"

## 📝 使用场景

### 维修人员
1. 点击批次工单卡片
2. 查看工单沟通记录，了解问题背景
3. 查看签字凭证（如果现场人员已上传）
4. 选择具体设备进行维修

### 现场人员
1. 点击批次工单卡片
2. 使用聊天功能与维修人员沟通
3. 查看已上传的签字凭证
4. 选择具体设备查看详情

### 管理员
1. 点击批次工单卡片
2. 监控工单沟通记录
3. 查看签字凭证状态
4. 了解工单整体进度

## 🎉 优势

- **一站式信息**: 在设备选择前就能了解所有工单级别的信息
- **提高效率**: 减少页面跳转，快速查看关键信息
- **便捷沟通**: 直接在设备选择页面就能与相关人员沟通
- **签字确认**: 快速查看客户签字状态，确保流程合规
