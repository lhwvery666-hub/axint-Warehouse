## 🎬 操作流程图

### 添加设备流程

```
批次详情页
   ↓
点击 [添加设备] 按钮
   ↓
弹出添加设备对话框
   ↓
填写设备信息
   - 设备序列号 *
   - 产品型号 *
   - 物料名称
   - 故障描述
   - ...
   ↓
点击 [添加设备] 按钮
   ↓
API: POST /api/tickets/batch-devices/[batchId]
   ↓
Toast: "设备已添加" ✅
   ↓
设备列表自动刷新
```

---

### 编辑设备流程

```
批次详情页 → 设备列表
   ↓
点击设备行的 [编辑] 按钮
   ↓
弹出编辑设备对话框（预填充数据）
   ↓
修改需要更新的字段
   ↓
点击 [保存修改] 按钮
   ↓
API: PUT /api/tickets/batch-devices/[batchId]
   ↓
Toast: "设备信息已更新" ✅
   ↓
设备列表自动刷新
```

---

### 删除设备流程

```
批次详情页 → 设备列表
   ↓

   ↓
弹出确认对话框

Toast: "设备已删除" ✅

设备从列表中消失

数据库：Status = 'Deleted'（软删除）
```

## 🔔 提示和技巧

### 💡 专业提示

1. **批量添加设备**
   - 虽然对话框一次只能添加一台，但可以连续快速添加
   - 未来版本将支持Excel批量导入

2. **编辑模式的优势**
   - 已完成的工单默认只读，避免误操作
   - 需要修改时，点击"编辑"按钮即可
   - 修改完成后会自动退出编辑模式

3. **软删除的好处**
   - 删除的数据仍在数据库中
   - 可以通过SQL查询恢复
   - 历史记录完整保留

4. **权限最小化原则**
   - 每个角色只能编辑自己负责的数据
   - 防止跨权限修改
   - 数据安全性更高
