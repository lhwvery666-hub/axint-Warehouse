## 完整流程测试

### 第1步：现场人员创建批次工单

1. 使用现场人员账号登录
2. 进入"故障报修"页面 (`/report`)
3. 填写项目信息：
   - 项目名称：测试项目
   - 项目位置：测试地点
   - 联系人：测试联系人
   - 联系电话：13800138000
4. 点击"添加设备"按钮，添加2台设备
5. 为每台设备填写：
   - 设备序列号：TEST001, TEST002
   - 产品型号：NC100
   - 物料名称：通用电源
   - 故障描述：无法开机
6. 点击"提交批次工单 (2台设备)"

**预期结果**：
- ✅ 弹出成功提示，显示批次号（例如：WO2602259788）
- ✅ 工单状态：`Warehouse_Confirming`
- ✅ 界面提示"批次工单模式"

---

### 第2步：仓库管理员确认设备并填写出厂日期

1. 使用仓库管理员账号登录
2. 进入"仓库管理工作台" (`/warehouse/dashboard`)
3. 在"待确认批次"标签页，看到刚创建的批次工单
4. 点击批次卡片，进入确认界面
5. 为每台设备选择出厂日期：
   - 设备1：2024-06-15
   - 设备2：2024-07-20
6. 点击"确认批次设备 (2台)"

**预期结果**：
- ✅ 弹出成功提示："批次设备已确认，状态已更新为待维修检查"
- ✅ 工单状态：`Warehouse_Confirmed`
- ✅ 系统自动计算保修状态（保内/过保）

---

### 第3步：维修人员检查设备并填写报告

1. 使用维修人员账号登录
2. 在首页或"维修工单管理"页面，找到批次工单
3. 点击进入批次详情页 (`/batch/[id]`)
4. 查看设备列表，确认可以看到：
   - ✅ 出厂日期列
   - ✅ 保修状态列（保内/过保）
5. 点击"编辑维修报告"按钮
6. 在弹窗中为每台设备填写：
   - 维修内容：更换电源模块
   - 维修费用：0（保内免费）
7. 点击"保存"

**预期结果**：
- ✅ 弹出成功提示："维修报告已保存并提交"
- ✅ 工单状态：`Pending_Reporter_Confirm`
- ✅ 现场人员收到通知

---

### 第4步：现场人员查看报告并签字回传

1. 使用现场人员账号登录
2. 进入"故障报修"页面 (`/report`)
3. 在工单列表看到"待现场确认"的工单
4. 点击工单，弹出详情窗口
5. 点击"查看维修报告"按钮
6. 在弹窗中查看维修报告内容
7. 准备一张签字后的报告照片（手写或盖章）
8. 上传签字照片
9. 点击"保存并发送"

**预期结果**：
- ✅ 弹出成功提示："签字照片已上传，维修人员可以开始维修"
- ✅ 工单状态：`Technician_Repairing`
- ✅ 维修人员可以看到签字凭证

---

### 第5步：维修人员完成维修

1. 使用维修人员账号登录
2. 进入批次详情页 (`/batch/[id]`)
3. 查看签字凭证（点击图片可放大）
4. 确认签字无误后，点击"完成维修"按钮
5. 在确认对话框中点击"确认"

**预期结果**：
- ✅ 弹出成功提示："维修工作已完成，批次工单已流转至商务审核"
- ✅ 工单状态：`Business_Review`
- ✅ 商务人员收到通知

---

### 第6步：商务人员确认收款和开票

1. 使用商务人员账号登录
2. 进入"商务管理控制台" (`/business`)
3. 切换到"待审核批次"标签页
4. 看到待审核的批次工单，点击进入
5. 选择"是否需要收费"：
   - **保内免费**：选择"否" → 直接点击"完成审核"
   - **过保收费**：选择"是" → 填写费用、客户名称 → 确认收款 → 确认开票 → 点击"完成审核"
6. 点击"完成审核"

**预期结果**：
- ✅ 弹出成功提示："商务审核完成，批次工单已转至仓库发货环节"
- ✅ 工单状态：`Warehouse_Shipping`
- ✅ 仓库管理员收到通知

---

### 第7步：仓库管理员发货

1. 使用仓库管理员账号登录
2. 进入"仓库管理工作台" (`/warehouse/dashboard`)
3. 切换到"待发货批次"标签页
4. 看到待发货的批次工单，点击进入
5. 选择发货方式：
   - **发回客户**：
     - 选择发货日期
     - 填写快递单号：SF1234567890
     - 填写发货数量：2
     - 点击"确认发货"
   - **产品入库**：
     - 直接点击"确认入库"
6. 点击确认按钮

**预期结果**：
- ✅ 弹出成功提示："批次设备已发回客户，共 2 台" 或 "批次设备已入库，共 2 台"
- ✅ 工单状态：`Completed`
- ✅ 流程结束

---

### 第8步：验证完成状态

1. 任意账号登录
2. 进入批次详情页 (`/batch/[id]`)
3. 查看时间线组件，确认所有步骤都已完成
4. 查看设备列表，所有设备状态为"已完成"

## 常见问题排查

### 问题1：仓库管理员看不到待确认批次

**可能原因**：
- 批次工单状态不是 `Warehouse_Confirming` 或 `Created`
- API `/api/tickets/warehouse-pending-batches` 返回错误

**排查步骤**：
```sql
-- 检查批次工单状态
SELECT BatchId, Status, COUNT(*) as DeviceCount
FROM Repair_Tickets
WHERE BatchId IS NOT NULL
GROUP BY BatchId, Status
```

### 问题2：维修人员无法编辑维修报告

**可能原因**：
- 工单状态还是 `Warehouse_Confirming`（仓库未确认）
- 仓库管理员还没有填写出厂日期

**排查步骤**：
```sql
-- 检查工单状态和出厂日期
SELECT ID, DeviceSN, Status, ManufactureDate
FROM Repair_Tickets
WHERE BatchId = 'WO2602259788'
```

### 问题3：商务人员看不到待审核批次

**可能原因**：
- 维修人员还没有完成维修
- 工单状态不是 `Business_Review`

**排查步骤**：
```sql
-- 检查工单状态
SELECT BatchId, Status, TechnicianCompletedAt, TechnicianCompletedBy
FROM Repair_Tickets
WHERE BatchId = 'WO2602259788'
```
