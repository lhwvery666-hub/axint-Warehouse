### 修复2：添加设备列表点击入口

**文件**: `components/batch-work-order-detail.tsx`

**修复位置**: 设备列表 `TableRow`（第578-581行）

**修复前**:
```typescript
<TableRow
  key={device.id}
  className="hover:bg-muted/50"
>
```

**修复后**:
```typescript
<TableRow
  key={device.id}
  className="hover:bg-muted/50 cursor-pointer"
  onClick={() => {
    // 点击设备行，跳转到单个设备的工作台页面
    router.push(`/repairs/detail/${device.id}`)
  }}
>
```

**功能说明**:
- ✅ 添加 `cursor-pointer` 样式，鼠标悬停显示手型光标
- ✅ 添加 `onClick` 事件，点击设备行跳转到单个设备工作台
- ✅ 跳转路径：`/repairs/detail/${device.id}`
