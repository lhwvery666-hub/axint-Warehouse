# PDF 下载功能

## 📋 功能说明

在维修报告打印页面添加了"下载为PDF"功能，方便用户保存报告为PDF文件。

---

## 🎯 使用方法

### 步骤1：打开维修报告页面
```
工单列表 → 点击工单 → "查看维修报告" 或 "打印报告"
```

### 步骤2：点击"下载为PDF"按钮
在页面顶部，绿色的按钮：

```
┌──────────────────────────────────────┐
│ [返回]  [下载为PDF] [打印报告]        │
└──────────────────────────────────────┘
```

### 步骤3：在打印对话框中保存
打印对话框会自动打开，请按以下步骤操作：

#### Windows 系统
1. **目标打印机**：选择"Microsoft Print to PDF"或"另存为PDF"
2. 点击"打印"按钮
3. 选择保存位置
4. 输入文件名（如：`维修报告-WO2602249788.pdf`）
5. 点击"保存"

#### Mac 系统
1. 点击左下角的"PDF"下拉菜单
2. 选择"存储为PDF"
3. 输入文件名
4. 选择保存位置
5. 点击"保存"

#### Chrome/Edge 浏览器
1. **目标打印机**：选择"另存为PDF"
2. 点击"保存"按钮
3. 选择保存位置并命名

## 💡 常见问题

### Q1：为什么点击"下载为PDF"后没有直接下载？

**A：** 这是正常的。"下载为PDF"功能会打开浏览器的打印对话框，您需要：
1. 在打印对话框中选择"另存为PDF"
2. 选择保存位置
3. 点击"保存"

这样做的好处是：
- ✅ 可以自定义文件名
- ✅ 可以选择保存位置
- ✅ 可以预览打印效果
- ✅ 保留所有样式和格式

---

### Q2：打印对话框中找不到"另存为PDF"选项？

**A：** 不同系统和浏览器的选项名称可能不同：

**Windows 系统**：
- "Microsoft Print to PDF"
- "Save as PDF"
- "另存为PDF"

**Mac 系统**：
- 点击左下角"PDF"菜单
- 选择"存储为PDF"

**Chrome/Edge 浏览器**：
- "另存为PDF"
- "Save as PDF"

---

### Q3：PDF中显示了不需要的按钮和提示？

**A：** 这是不正常的。正常情况下，打印时会自动隐藏：
- ❌ 返回按钮
- ❌ 下载为PDF按钮
- ❌ 打印报告按钮
- ❌ 操作提示
- ❌ 现场确认界面

如果出现这个问题：
1. 确保使用最新版本的浏览器
2. 刷新页面后重试
3. 检查打印设置中的"背景图形"选项

---

### Q4：可以批量下载多个工单的PDF吗？

**A：** 目前不支持批量下载。每个工单需要单独下载。

建议流程：
```
1. 打开工单1 → 下载为PDF
2. 打开工单2 → 下载为PDF
3. ...
```

您可以将文件命名为：
- `维修报告-WO2602249788.pdf`
- `维修报告-客户名称-日期.pdf`

---

### Q5：PDF文件太大怎么办？

**A：** 如果PDF文件过大（通常因为包含签字照片）：

1. **压缩PDF**：使用在线工具或Adobe Acrobat
2. **调整图片质量**：上传签字照片前先压缩
3. **分开保存**：
   - 维修报告保存为一个PDF
   - 签字照片单独下载

---

### Q6：打印出来的PDF是空白的？

**A：** 可能的原因：

1. **等待加载完成**
   - 确保页面完全加载后再下载
   - 等待图片（如签字照片）加载完成

2. **检查浏览器设置**
   - 启用"背景图形"选项
   - 检查缩放比例是否为100%

3. **尝试其他浏览器**
   - Chrome（推荐）
   - Edge
   - Firefox

## 🔧 技术实现

### 打印样式优化

使用CSS的 `@media print` 查询，自动隐藏不需要打印的元素：

```css
@media print {
  .no-print {
    display: none !important;  /* 隐藏按钮和提示 */
  }
  
  .print-container {
    padding: 0;
    max-width: 100%;
  }
  
  .print-content {
    page-break-inside: avoid;  /* 避免跨页 */
  }
}
```

## 📊 与打印功能的区别

| 功能 | 打印报告 | 下载为PDF |
|-----|---------|----------|
| **目的** | 打印纸质报告 | 保存电子文件 |
| **输出** | 纸张 | PDF文件 |
| **操作** | 选择打印机 → 打印 | 选择"另存为PDF" → 保存 |
| **用途** | 给客户签字 | 存档、邮件发送 |
| **是否需要打印机** | ✅ 需要 | ❌ 不需要 |
| **可以编辑** | ❌ 不可以 | ❌ 不可以 |
| **可以分享** | ❌ 不方便 | ✅ 方便 |
