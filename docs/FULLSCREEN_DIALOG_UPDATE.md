# 设备详情弹窗改为全屏模式

**日期**: 2026-02-26  
**状态**: ✅ 已完成

---

## 📋 问题描述

用户反馈：
> "这个页面太拥挤了能不能全屏不是这种窗口模式"

**问题分析**:
- 设备维修详情弹窗使用了 `max-w-7xl max-h-[90vh]` 的限制
- 在窗口模式下，内容显示拥挤，进度条、必填字段等信息不够清晰
- 全屏模式可以提供更好的阅读体验和操作空间

---

## ✅ 解决方案

### 修改的文件

1. **`components/batch-work-order-detail.tsx`** - 批次工单中的设备详情弹窗
2. **`components/repairs-panel.tsx`** - 维修面板中的工单详情弹窗

### 核心修改

**修改前**:
```typescript
<DialogContent className="max-w-7xl max-h-[90vh] overflow-y-auto">
  <DialogHeader>
    <DialogTitle>设备维修详情</DialogTitle>
  </DialogHeader>
  <div className="py-2">
    <RepairDetail taskId={selectedDeviceId} onBack={...} inBatchMode={true} />
  </div>
</DialogContent>
```

**修改后**:
```typescript
<DialogContent className="max-w-full w-screen h-screen p-0 gap-0 bg-background">
  <DialogHeader className="sr-only">
    <DialogTitle>设备维修详情</DialogTitle>
  </DialogHeader>
  <div className="h-full overflow-y-auto">
    <RepairDetail taskId={selectedDeviceId} onBack={...} inBatchMode={true} />
  </div>
</DialogContent>
```

### 关键样式说明

| 样式类 | 作用 | 原值 | 新值 |
|--------|------|------|------|
| `max-w-*` | 最大宽度 | `max-w-7xl` (80rem) | `max-w-full` |
| `w-*` | 宽度 | 未设置 | `w-screen` (100vw) |
| `h-*` | 高度 | `max-h-[90vh]` | `h-screen` (100vh) |
| `p-*` | 内边距 | 默认 | `p-0` (移除默认内边距) |
| `gap-*` | 间距 | 默认 | `gap-0` (移除 Dialog 默认间距) |
| `overflow-y-auto` | 滚动 | 在外层 | 移到内层 `<div>` |
| `DialogHeader` | 标题栏 | 可见 | `sr-only` (仅屏幕阅读器可见) |

## 🔧 技术实现细节

### 1. 全屏样式组合

```typescript
className="max-w-full w-screen h-screen p-0 gap-0 bg-background"
```

- `max-w-full`: 移除最大宽度限制
- `w-screen`: 宽度设置为100vw（整个视口宽度）
- `h-screen`: 高度设置为100vh（整个视口高度）
- `p-0`: 移除默认内边距
- `gap-0`: 移除 DialogHeader 和 DialogContent 之间的默认间距
- `bg-background`: 设置背景色与应用一致

### 2. 标题栏处理

```typescript
<DialogHeader className="sr-only">
  <DialogTitle>设备维修详情</DialogTitle>
</DialogHeader>
```

- 使用 `sr-only` 类将标题栏隐藏（仅屏幕阅读器可见）
- 保留了无障碍访问（a11y）要求
- 节省了垂直空间
- RepairDetail 组件自带的头部会作为实际的标题

### 3. 滚动容器调整

```typescript
<div className="h-full overflow-y-auto">
  <RepairDetail ... />
</div>
```

- 将滚动控制移到内层容器
- 确保整个页面可以正常滚动
- 避免双滚动条问题
