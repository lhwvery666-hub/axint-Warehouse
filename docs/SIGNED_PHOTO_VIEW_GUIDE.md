## ⚠️ 常见问题

### Q1：为什么我看不到签字照片？

**A：请检查以下几点**
1. 现场人员是否已经上传照片？
   - 检查方法：工单详情页 → 签字凭证板块
   - 如果显示"暂无签字凭证"，说明还没上传

2. 照片是否已经提交到数据库？
   - 现场人员上传照片后，需要点击"确认提交"
   - 提交前，照片只在当前浏览器显示

3. 您是否有权限查看该工单？
   - 现场人员只能看自己创建的工单
   - 其他角色可以看所有工单

---

### Q2：上传照片后，刷新页面照片不见了？

**A：照片还没有提交到数据库**

```
正确流程：
1. 上传照片 → 照片显示为"⏳ 待提交"
2. 点击"确认提交"按钮
3. ✅ 照片变为"✓ 已回传到数据库"
4. 此时刷新页面，照片还在
```

---

### Q3：我是维修人员，怎么快速查看客户是否已签字？

**A：推荐使用打印页面查看**

```
1. 工单列表 → 找到工单
2. 点击"查看维修报告"
3. ✅ 如果页面顶部有绿色的签字照片区域 = 已签字
4. ❌ 如果没有 = 还没签字
```

---

### Q4：可以删除已上传的签字照片吗？

**A：目前不支持删除，但可以重新上传**

```
现场人员操作：
1. 进入打印页面
2. 如果看到"重新选择"按钮，点击它
3. 重新上传新的照片
4. 点击"确认提交"
5. ✅ 新照片会覆盖旧照片
```

---

### Q5：签字照片存储在哪里？

**A：存储在两个地方**

1. **服务器硬盘**：`public/uploads/signed-reports/`
   - 实际的图片文件
   - 文件名格式：`{工单号}-{时间戳}-{随机码}.jpg`

2. **数据库**：`Repair_Tickets` 表的 `SignedReportPhoto` 字段
   - 存储照片的相对路径
   - 例如：`uploads/signed-reports/WO123-1708776543210-a1b2c3d.jpg`
