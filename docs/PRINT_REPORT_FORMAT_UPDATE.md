# 维修报告格式更新（按用户图片格式）

## 📋 更新说明

根据用户提供的参考图片，对维修报告的打印格式进行了全面调整，以匹配实际使用的格式。

---

## 🎯 主要变化

### 1. 基本信息表格布局调整

**旧格式**：
```
工单号 | [value] | 项目名称 | [value]
客户名称 | [value] | 联系方式 | [value]
客户地址 | [value span 3]
接收日期 | [value] | 完成日期 | [value]
```

**新格式**：
```
收货日期 | [value] | 单据单号 | [value]
客户名称 | [value] | 项目名称 | [value]
客户地址 | [value] | 联系人/电话 | [value]
From | - | 是否过保 | 是
```

**改进点**：
- ✅ "工单号"改为"单据单号"
- ✅ "接收日期"改为"收货日期"，放在第一行
- ✅ 新增"From"字段（目前留空）
- ✅ 新增"是否过保"字段（目前固定为"是"）
- ✅ "联系方式"改为"联系人/电话"

---

### 2. 维修明细表格简化

**旧格式**：
```
序号 | 设备型号 | 序列号 | 数量 | 维修内容 | 改进建议 | 维修费用
```

**新格式**：
```
序号 | 设备型号 | 产品序列号 | 数量 | 维修主要内容 | 费用(元)
```

**改进点**：
- ✅ "序列号"改为"产品序列号"
- ✅ "维修内容"改为"维修主要内容"
- ✅ 移除"改进建议"列（简化表格）
- ✅ "维修费用(元)"改为"费用(元)"

---

### 3. 合计行格式调整

**旧格式**：
```
合计： | [quantity] | | ¥[cost]
```

**新格式**：
```
维修数量合计 | [quantity] | 维修费用合计 | [cost]
插入项
```

**改进点**：
- ✅ 合计行分为两部分：数量合计和费用合计
- ✅ 新增"插入项"行（预留扩展位置）

---

### 4. 底部区域完全重构

**旧格式**：
```
┌─────────────────┬─────────────────┐
│ 返回方式：配套  │ 制单人：xxx     │
├─────────────────┼─────────────────┤
│ 复核：          │ 客户签字确认：  │
│                 │ [照片或留空]    │
├─────────────────┴─────────────────┤
│ 外购产品：                        │
├───────────────────────────────────┤
│ 维修负责人：xxx │ 日期：xxxx-xx-xx│
└───────────────────────────────────┘

联系人：黄工
电话：13530978726
维修部地址：深圳市...
```

**新格式**：
```
┌─────────────────────────────────────┐
│ 备  注                              │
│                                     │
│ [大块留空区域]                      │
│                                     │
├─────────────────────────────────────┤
│ 是否高保维修：                      │
├─────────────────────────────────────┤
│ 客户签字确认（盖章）：              │
│                                     │
│ [照片或留空]                        │
│                                     │
├─────────────────────────────────────┤
│ 日期：                              │
├─────────────────────────────────────┤
│ 返回方式：配套                      │
├─────────────────────────────────────┤
│ ☑ 代翻维修 ☐ 发票维修 ☐ 不维修      │
│ 制单人：xxx          ☐ 外购产品     │
└─────────────────────────────────────┘

联系人：黄工  电话：13530978726
维修部地址：深圳市宝安区石岩街道办民生一路嘉一达科技园6栋2楼
```

**主要改进**：
- ✅ 备注区域扩大，提供更多手写空间
- ✅ 新增"是否高保维修"字段
- ✅ 客户签字确认单独成行，更醒目
- ✅ 新增"日期"字段（签字日期）
- ✅ 底部签名区域改用复选框样式：
  - ☑ 代翻维修（默认选中）
  - ☐ 发票维修
  - ☐ 不维修
  - ☐ 外购产品
- ✅ 联系人信息移到最底部，横排显示
