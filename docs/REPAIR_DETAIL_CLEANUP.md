# 维修详情页面清理 - 移除重复功能

## 📋 概述

从单个设备维修详情页面移除了"工单沟通记录"和"签字凭证"两个面板，因为这些功能已经在批次级别的页面提供，避免重复显示。

## 🎯 修改内容

### 1️⃣ 移除的面板

#### ❌ 工单沟通记录（panel5）
- **原因**: 此功能已在以下页面提供：
  - 批次工单详情页 (`batch-work-order-detail.tsx`)
  - 批次设备选择页 (`repair-page.tsx` 的 `batchSelect` 视图)
- **绑定级别**: 聊天记录绑定到批次工单号（`batchId`），不是单个设备
- **位置**: 更适合在批次级别查看，而非单个设备详情

#### ❌ 签字凭证（panel6）
- **原因**: 签字照片是针对整个批次工单，不是单个设备
- **位置**: 已在批次级别页面提供完整的查看和操作功能
- **功能**: 查看大图、下载、复制链接等功能在批次页面都有

### 2️⃣ 修改默认展开状态

**修改前:**
```typescript
<Accordion type="multiple" defaultValue={["panel1"]} className="w-full">
```

**修改后:**
```typescript
<Accordion type="multiple" defaultValue={[]} className="w-full">
```

**效果**: 打开设备详情时，所有折叠面板默认收起，用户可以根据需要点击展开。

### 3️⃣ 清理导入

移除了不再使用的导入：
```typescript
// 已移除
import { TicketChat } from "@/components/TicketChat"
import { UserRole } from "@/lib/enums"
```

## 🎯 功能位置指引

### 如何查看工单沟通记录？

**方式1: 批次工单详情页**
1. 进入批次工单详情页（`/batch/[batchId]`）
2. 向下滚动到"工单沟通记录"卡片
3. 查看和发送消息

**方式2: 批次设备选择页**
1. 从工单列表点击批次工单卡片
2. 进入"选择要处理的设备"页面
3. 设备列表下方有"工单沟通记录"卡片

### 如何查看签字凭证？

**方式1: 批次工单详情页**
1. 进入批次工单详情页（`/batch/[batchId]`）
2. 向下滚动到"签字凭证"卡片
3. 查看照片、下载、复制链接

**方式2: 批次设备选择页**
1. 从工单列表点击批次工单卡片
2. 进入"选择要处理的设备"页面
3. 设备列表下方有"签字凭证"卡片

**方式3: 维修报告打印页**
1. 访问 `/repairs/print/[batchId]`
2. 页面顶部显示签字照片状态
3. 现场人员可上传签字照片

## ✅ 优势

### 1️⃣ 避免信息重复
- 批次级别的信息不会在每个设备详情中重复显示
- 减少用户困惑："我应该在哪里查看/发送消息？"

### 2️⃣ 更清晰的信息层级
- **批次级别**: 工单沟通、签字凭证
- **设备级别**: 现场报告、维修记录、物流信息

### 3️⃣ 更好的用户体验
- 默认折叠所有面板，页面更简洁
- 用户可以快速浏览各个板块的标题
- 点击需要的板块展开查看详情

### 4️⃣ 减少维护成本
- 同一功能只需在一个地方维护
- 减少代码重复
- 降低 bug 出现的可能性
