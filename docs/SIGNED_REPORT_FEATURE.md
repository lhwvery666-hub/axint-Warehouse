# 签字报告功能说明

## 📋 功能概述

维修报告确认流程中，**权限已严格分离**：
- **维修人员**：负责标记"已完成维修"
- **现场人员**：负责标记"是否回寄" + 上传签字报告照片

## 🔐 权限控制

### 维修人员权限
- ✅ 可以修改：**已完成维修**开关
- ❌ 不能修改：**是否回寄**开关（只读）
- ❌ 不能上传：签字照片（不显示上传界面）

### 现场人员权限
- ✅ 可以修改：**是否回寄**开关
- ❌ 不能修改：**已完成维修**开关（只读）
- ✅ **必须上传**：签字报告照片（打印后签字拍照）

### 其他角色
- 管理员、商务、仓库：只能查看，不能修改任何开关

## 📸 签字照片上传

### 上传要求
- **文件格式**：JPG、PNG
- **文件大小**：最大 5MB
- **上传时机**：现场人员确认时必须上传

### 操作流程
1. 现场人员打开维修报告打印页面
2. 点击"打印报告"按钮打印纸质报告
3. 在纸质报告上手写签字
4. 拍照上传签字后的报告
5. 选择每个设备是否需要回寄
6. 点击"确认提交"

## 🚀 部署步骤

1. **运行数据库迁移**
   ```bash
   npx tsx scripts/add-signed-report-photo-column.ts
   ```

2. **创建上传目录**（服务器会自动创建，也可手动创建）
   ```bash
   mkdir -p public/uploads/signed-reports
   ```

3. **重启应用**
   ```bash
   npm run build
   npm run start
   ```

4. **验证功能**
   - 现场人员登录测试签字照片上传
   - 维修人员登录测试"已完成维修"修改
   - 确认其他角色无法修改
