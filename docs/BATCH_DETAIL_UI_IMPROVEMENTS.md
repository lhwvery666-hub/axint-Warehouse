# 批次详情页面界面优化

## 更新日期
2026-02-25

## 改进内容

### 1. 权限控制优化

**问题**：现场人员（Reporter）能看到"物料名称"和"物料代码"等公司内部信息。

**解决方案**：
- 根据用户角色动态控制表格列的显示
- 现场人员只能看到：序号、设备序列号、产品型号、出厂日期、保修状态、状态、故障描述
- 内部人员（维修人员、仓库、商务、管理员）可以看到：包括物料名称在内的所有信息

```typescript
// TableHeader
{user?.role !== UserRole.REPORTER && <TableHead>物料名称</TableHead>}

// TableBody
{user?.role !== UserRole.REPORTER && <TableCell>{device.deviceName || "-"}</TableCell>}
```

### 2. 界面简化优化

**问题**：
- 上面显示一个完整的设备编辑表格（BatchDeviceManager）
- 下面又显示一个详细的只读表格
- 造成界面冗余，用户困惑

**解决方案**：
- 删除上面的完整编辑表格
- 在设备列表标题栏只保留"添加设备"按钮
- 点击按钮弹出添加设备对话框

**实现方式**：
```typescript
// batch-device-manager.tsx
interface BatchDeviceManagerProps {
  buttonOnly?: boolean  // 新增属性
}

// 根据 buttonOnly 控制显示模式
{buttonOnly ? (
  // 只显示按钮
  <Button onClick={handleOpenAdd}>
    <Plus className="w-4 h-4 mr-2" />
    添加设备
  </Button>
) : (
  // 完整模式：标题 + 按钮 + 表格
  ...
)}
```

### 3. 产品类别字段删除

**问题**：批次详情顶部显示"产品类别"，但这是第一个设备的分类，可能误导用户。

**解决方案**：
- 删除批次详情顶部的"产品类别"字段
- 每个设备的详细分类在设备详情中显示

### 4. 布局改进

**之前**：
```
工单基础信息
├─ 工单号
├─ 项目名称
├─ 项目位置
├─ 联系信息
├─ 产品类别  ❌ (已删除)
└─ 设备数量

[完整的设备编辑表格]  ❌ (已删除)

设备列表
└─ [详细的只读表格]
```

**现在**：
```
工单基础信息
├─ 工单号
├─ 项目名称
├─ 项目位置
├─ 联系信息
└─ 设备数量

设备列表 [+ 添加设备按钮]  ✅
└─ [详细表格]
   ├─ 根据角色控制列显示  ✅
   └─ 点击查看详情按钮查看完整信息  ✅
```
